# ARTCRAFTS — Deployment Guide

> **Architecture**: React 19 SPA on **Vercel** (frontend) + Node.js 22 API on **Render** (backend)

---

## Quick Overview

| Layer | Platform | What it serves |
|-------|----------|----------------|
| **Frontend** | Vercel | Vite-built React SPA (`dist/`) |
| **Backend** | Render | Node.js API (`server/index.mjs`) + SQLite DB |
| **Storage** | Supabase | Image uploads (with local disk fallback) |
| **Payments** | Razorpay | UPI, Cards, Net Banking, COD |
| **Email** | Resend | Order confirmations, contact notifications |

---

## 1. Deploy Backend on Render

### Option A: One-Click Blueprint

1. Go to [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**
2. Connect your GitHub repo (`harshavk1603/ARTCRAFTS`)
3. Render auto-detects `render.yaml` and configures everything
4. Set the secret environment variables when prompted (see below)

### Option B: Manual Web Service

1. **New Web Service** → Connect repo
2. **Build Command**: `npm ci`
3. **Start Command**: `node server/index.mjs`
4. **Runtime**: Node
5. **Plan**: Starter (or higher)
6. Add a **Persistent Disk**: mount at `/opt/render/project/data`, 1 GB
7. Set environment variables (see below)

### Required Environment Variables (Render)

| Variable | Value |
|----------|-------|
| `NODE_ENV` | `production` |
| `PORT` | `10000` |
| `DB_PATH` | `/opt/render/project/data/artcrafts.sqlite` |
| `FRONTEND_URL` | `https://your-app.vercel.app` ← set after Vercel deploy |
| `SESSION_SECRET` | Random 64-char string (auto-generated by blueprint) |
| `ADMIN_EMAIL` | Your admin email |
| `ADMIN_PASSWORD` | Strong password (≥10 chars) |
| `SUPABASE_URL` | Your Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key |
| `SUPABASE_SECRET_KEY` | Same as service role key |
| `SUPABASE_STORAGE_BUCKET` | `artcrafts-media` (or your bucket name) |
| `RAZORPAY_KEY_ID` | Razorpay key (optional, enables payments) |
| `RAZORPAY_KEY_SECRET` | Razorpay secret |
| `RESEND_API_KEY` | Resend key (optional, enables emails) |

### Verify Backend

```
curl https://your-app.onrender.com/api/health
```

Expected: `{"status":"ok","database":"ok",...}`

## 2. Deploy Frontend on Vercel

1. Go to [Vercel Dashboard](https://vercel.com/dashboard) → **Add New Project**
2. Import your GitHub repo (`harshavk1603/ARTCRAFTS`)
3. Vercel auto-detects `vercel.json` — framework: Vite
4. Set the environment variable:

| Variable | Value |
|----------|-------|
| `VITE_API_URL` | `https://your-app.onrender.com` ← your Render URL |

5. Click **Deploy**

### How API Calls Work

- **Local dev**: Vite proxies `/api/*` → `http://127.0.0.1:3001`
- **Production**: `src/api.js` reads `VITE_API_URL` env var and prefixes all API calls with it

---

## 3. Connect Frontend ↔ Backend

After both are deployed:

1. **On Render**: Set `FRONTEND_URL` = `https://your-app.vercel.app`
2. **On Vercel**: Set `VITE_API_URL` = `https://your-app.onrender.com`
3. Redeploy both services

This enables:
- CORS headers on the backend to accept requests from Vercel
- CSP headers to allow the frontend origin
- Secure cookies with `SameSite=None; Secure` for cross-origin auth

## Important Notes

> **SQLite on Render**: Render's free tier filesystem is ephemeral. You **must** attach a persistent disk (configured in `render.yaml`) or your database will be lost on each deploy. The disk is mounted at `/opt/render/project/data`.

> **First Deploy**: The backend auto-creates the database, seeds initial products/categories/artisans, and provisions the admin account from `ADMIN_EMAIL` + `ADMIN_PASSWORD` environment variables.

> **Supabase Storage**: If Supabase keys are not configured, image uploads fall back to local disk (`uploads/` directory). In production on Render, configure Supabase for persistent image storage.

> **Razorpay**: If Razorpay keys are not set, the checkout offers only Cash on Delivery in production mode.
